# 🎆 Custom New Year Wish Card Generator

A simple, interactive, and mobile-responsive web application that allows users to generate personalized Sinhala and Tamil New Year wish cards. Users can enter their name, and the app uses the HTML5 Canvas API to draw it onto a beautifully designed template.

## ✨ Features

* **Custom Image Generation:** Dynamically writes the user's name onto a pre-designed template.
* **One-Click Download:** Users can instantly download their generated image.
* **Mobile Responsive:** Perfectly adapts to any screen size.
* **Smooth Animations:** Includes CSS animations for a modern user experience.

## 🛠️ Technologies Used

* **HTML5** (Canvas API)
* **CSS3** (Flexbox, Animations)
* **Vanilla JavaScript** (DOM Manipulation)

## 💻 How to Run Locally

Because this project uses the HTML5 `<canvas>` element to manipulate images, running the `index.html` file directly by double-clicking it may cause CORS (Cross-Origin Resource Sharing) issues when downloading.

To run it properly on your computer:
1. Clone this repository or download the files.
2. Open the project folder in **VS Code**.
3. Use the **Live Server** extension to open `index.html`.
